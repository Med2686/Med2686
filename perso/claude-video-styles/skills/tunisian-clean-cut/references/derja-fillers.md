# Derja / French / English fillers and tics

What the user says that a viewer hears as "the editor left a mistake in". Every entry is a **lead**: decide from
the meaning of the sentence. The same word is often content in another sentence (see "keep when").
Arabizi: 3 = ع, 7 = ح, 9 = ق, 5 = خ, ch = ش, gh = غ, dh = ذ.

## How the three Whisper passes write them

| He says (arabizi) | Arabic script | EN pass writes | FR pass writes | AR pass writes |
|---|---|---|---|---|
| ena / ana (I) | أنا / آنا | Anna, And I | Ena, Elle a | انا (sometimes a loop « انا، انا… ») |
| ena personnellement | أنا personnellement | Anna, personally | Ena personnellement | أنا شخصياً (translated) |
| ki nchouf (when I see) | كي نشوف | Kinshuv, I can shove | Kinshuv, qui me chauve | |
| ama famma (but there is) | أما فما | My wife has | Ma femme a | اما فما |
| barcha (a lot) | برشا | | par shahajit | برشا / كثير |
| fhemt / fhemtni ? | فهمت / فهمتني | | | فهمت |
| ya3ni | يعني | Yani, I mean | ya3ni | يعني |
| Claude | | cloud | cloud, Claude | |

The EN pass is the most readable proxy for structure and repeats; the FR pass for French words; the AR pass
for the gist only (it translates to Modern Standard Arabic).

## Openers (start of a line)

| Tic | Arabic | Cut when | Keep when |
|---|---|---|---|
| ena personnellement / ana personnellement | أنا personnellement | it is throat-clearing before a restart: « ena personnellement, donc ena, ki nchouf » → keep from « ki nchouf » | it states his personal view as the claim: « w ana personnellement ma nchouf ken zouz 7ajet ya3mlou la différence » (kept in the ref-edit reel) |
| donc (empty starter) | | it starts a line without linking anything, or is followed by a restart « donc… donc ma » | it concludes: « donc ken enti ma 3andekch le recul » (a real « so ») |
| ok, okay, d'accord, behi | باهي | always as a tic at a line start or end | « behi » meaning "good" (« résultat behya ») is content |
| bon, alors, en fait, voilà, mela | ملا | as a launch sound | rarely content |
| ama (but) as a launch | أما | it opens a new take with no contrast | real contrast: « ama techniquement ghalta » |
| tawa (now) as a launch | توا | when it means "so, well" | when it means "now / these days": « tawa barcha 3bed t3allmou… » (kept) |
| n7eb n9ollek, kifech n9ollek | نحب نقلك / كيفاش نقلك | hesitation ("how do I say") | never content |
| ya jme3a | يا جماعة | always (unless the hook addresses the viewers on purpose) | |
| chnowa… (searching) | شنوة | the hesitating « chnowa… » before the word | a real question « ta3ref chnowa t'sal ? » |

## Anywhere

| Tic | Arabic | Notes |
|---|---|---|
| euh, heu, mmm, eeh, aaa, a held vowel | | Whisper drops them: measure them (quiet run under speech level, or a voiced run with a flat spectrum). Cut. |
| fhemt, fhemtni ? | فهمت | tic. Cut. |
| ya3ni (filler) | يعني | cut when it only buys time; keep when it means "it means": « chnowa ya3ni prompt ? » |
| d'accord, ok | | tic. Cut. |
| genre, quoi, tu vois, bref, c'est-à-dire, comment dire, en gros | | tic. Cut. |
| you know, like, basically | | tic. Cut. |
| kel3ada | كالعادة | tic ("as usual") unless it says something. |
| w kol, w hakka, et cetera, etc. | و كل / و هكا | trailing tic after an enumeration. Cut. |
| wala (trailing) | ولا / والا | cut a trailing « wala » that opens nothing ("…or"). Keep it inside a real alternative: « ynajja7 wala ma ynajja7ch » (succeeds or not). Takes joined by « wala » are still retakes: keep the last. |
| par exemple repeated | | a filler « par exemple » inside an enumeration that already started with one: keep the first, cut the repeat. |

## Not fillers (do not cut)

- A rephrase that adds meaning: « bech y7ot-ha mba3d l'editing » was refused as a cut on the kalfetni reel.
- Legit doubles: « chwaya chwaya » (slowly), « barcha barcha » used for emphasis, « kif kif » (same).
- Enumerations: « les idées de vidéo, le concept, le storytelling, les angles de caméra… » are content.
- A question he asks the viewer: « ta3ref chnowa t'sal ? », « kifech twajjahha ? ».
